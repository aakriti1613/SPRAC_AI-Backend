# Phase 8: evaluation report

Generated by `npm run registry:evaluate-sites`. Run date: 2026-11-19T13:09:45.933Z. AI model: gemini-3.8-flash. Requests: 30.

## What was compared

The same 30 website requests (`sparc/eval/requests.json`: 12 admin portals, 6 portfolios, 6 landing pages, 3 online stores, 3 booking sites) were built three ways:

- **(a) Templates only.** How the prototype worked: a fixed template per website type, and for a portal the preset modules of the chosen industry. A request is served only if a template exists for its type and, for a portal, the preset already contains every module the request needs.
- **(b) SPARC.** Plan the site, choose verified library components, assemble a project, run the checks and a real Vite build. Run twice: with the offline planner (no key needed) and with the Gemini planner.
- **(c) AI writes all the code.** One Gemini call writes the whole site as a single React file, which is wrapped in the smallest project that can build it. One attempt only, no repair.

A site **covers** a request when its own checks pass and at least 60% of the request's key words appear in it. For (b) the words are searched in the site's config (names, labels, headings); for (c) in the code.

## What this does and does not show

- It does **not** include the user study (people rating the four style levels). The protocol and the analysis script are ready (`docs/eval/USER_STUDY.md`, `registry/evaluation/ratings.js`); the ratings have to come from real people.
- "Covers the request" is a word check, not a human judgement of quality. It cannot tell a good design from a bad one.
- The AI-code system got one attempt with one prompt and one model. A person would retry on a build error; a better prompt or model would raise its numbers. Treat its numbers as a baseline for a single try.
- Time and token numbers depend on the day's Gemini load (retries are counted in `results.json`).
- The templates-only baseline is a model of the prototype's rules (template exists for the type, industry preset has the modules), not a run of the old pages by hand.
- Everything is one run on one machine. The raw numbers for every request are in `docs/eval/results.json`.
